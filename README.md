# FastTime

时间戳与日期互转，点击复制。

FastTime 是 Fast 系列的轻量 uTools 插件：直接在主搜索框输入时间，查看并复制答案，让日常排查日志、处理接口参数时的转换只需一次输入、一次选择。转换离线完成，不发送输入，不保存历史。

## 使用

1. 在 uTools 中为 FastTime 开启“允许推送内容到搜索框”。
2. 回到主搜索框，直接输入以下任一示例，无需 `FastTime` 前缀。
3. 点击结果，或选中后按回车，即可复制转换后的纯值，不含标签和时区说明。

```text
1700000000
1700000000123
2023-11-14
2023/11/14 22:13:20.123
2023-11-14T22:13:20.123Z
2023-11-15 06:13:20+08:00
```

时间戳同时显示本地时间和 UTC 时间，本地结果标注输入时间点的实际 UTC 偏移。日期输入同时输出秒级和毫秒级时间戳，保留毫秒精度。搜索 `FastTime` 可打开使用说明。

## 支持的格式

| 输入 | 范围与规则 |
| --- | --- |
| 时间戳 | 10 位秒级或 13 位毫秒级非负整数 |
| 日期 | `YYYY-MM-DD` 或 `YYYY/MM/DD`，仅日期按零点计算 |
| 日期时间 | 日期后追加 `HH:mm`、`HH:mm:ss` 或 `HH:mm:ss.SSS`；小数秒可为 1–3 位 |
| 显式时区 | 连字符日期时间支持空格或 `T` 分隔，并可追加 `Z` 或 `±HH:mm`；斜杠格式只支持空格分隔，不支持时区后缀 |

日期年份范围为 `0001–9999`；年月日、时分秒需补齐位数，日期分隔符需一致。未指定时区时使用电脑本地时区，省略秒按 `0` 计算。无效日期、自然语言、负数或小数时间戳，以及其他位数的时间戳不会产生结果。

## 本地开发与打包

项目使用 Vue 和 Vite。在项目根目录执行：

```sh
npm ci
npm run dev
```

在 uTools 开发者工具中选择 `public/plugin.json` 进行开发安装。其 `development.main` 指向 `http://localhost:5173`，开发期间需保持 Vite 服务运行。

```sh
npm test
npm run verify:build
```

`npm test` 检查转换与搜索框推送、复制行为；`npm run verify:build` 执行生产构建，并检查产物入口、资源及源码与产物的转换和复制行为是否一致。

构建输出位于 `dist/`。在 uTools 开发者工具中将 `dist/` 作为构建输出目录进行打包，发布入口为其中的 `plugin.json` 和 `index.html`。
