# Proposal

## Why

日常开发中，时间戳和日期之间的转换频繁且简单，打开转换面板、切换方向会打断工作。FastTime 将答案直接推送到 uTools 主搜索结果，让用户输入、查看、回车复制即可完成转换。

## What Changes

- 识别 10 位秒级和 13 位毫秒级整数时间戳，分别输出电脑本地时区（带 UTC 偏移）及 UTC 的日期时间。
- 识别明确支持的日期字符串及 ISO 8601 时间，分别输出秒级、毫秒级时间戳；保留毫秒精度。
- 使用 uTools 搜索结果推送能力，无需先输入功能关键词或打开插件界面；回车复制纯转换值。
- 为“允许推送内容到搜索框”提供开启说明，实际授权由用户在 uTools 内完成。
- 替换工程中的 hello、读文档演示入口和示例文件读取能力，保留既有 Vue/Vite 工程。
- 提供简洁使用说明入口与可用于插件发布的应用描述，说明功能、设计理念和使用方式。
- 首版不包含历史、批量转换、联网解析、任意自然语言日期或转换工作台。

- 后续优化：项目改名 FastTime；项目描述缩短至 25 字以内，复制提示改为悬停显示，时间戳输入同时给出本地和 UTC 时间。

## Capabilities

### New Capabilities

- `timestamp-conversion`: 明确格式的双向转换、时区处理、精度保留和严格日期校验。
- `search-result-push`: 搜索框匹配、动态推送、无界面复制、推送授权说明与应用使用介绍。

### Modified Capabilities

无。项目尚无既有规格。

## Impact

- `public/plugin.json`：移除演示功能，声明转换匹配、推送与一个说明指令。
- `public/preload.js` 及新增本地模块：转换逻辑、推送注册和复制处理，不再暴露文件读取能力。
- `src/App.vue`、`src/main.css`、`index.html`：替换演示界面为轻量说明页，正常转换不进入该页。
- `package.json` 和测试目录：增加转换与 uTools 集成边界测试，不新增运行时依赖。
- 新增应用描述文档，供复制到插件发布描述中；生产构建继续由 Vite 输出至 `dist/`。
- 不调用网络、不持久化用户输入；uTools 推送授权的具体入口和实际运行效果需在宿主内验证。
